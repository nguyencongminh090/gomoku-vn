## 1. Design brief (all three are analysis boards)
The board is the product. Every pixel of height below the 56 px header goes to the board: a `100svh` flex frame, the board cell with a definite height, and the panel scrolling inside itself. Chrome reuses `tokens.css` and `platform.css` (`ppanel`, `pbtn--ghost`, `pseg`, `pbadge`, `ptab`) on `body.pl`, the same language as the profile, puzzle and rankings pages. Controls follow one hierarchy: the timeline (slider plus counter), then 5 equal 44 px transport buttons with Play as the only filled (brand) control, then secondary actions as ghost buttons.

Notes that drove the choices:
- `ux-responsive-mobile-first`: breakpoint from content, at 860 px where the shell switches to the tab bar. Fluid grid, no fixed widths. → one desktop frame, one phone column.
- `vbase-layout-spacing` and `vbase-visual-principles`: one dominant element (the board) and proximity grouping (players and result, then playback, then list).
- `iconography` (#214): Phosphor Regular at 16/20, visible labels on secondary buttons, aria-labels on transport icons, targets ≥ 24 px (44 px on the transport row). The current page uses `ph-bold`, which goes.
- `ticket-rows` and the no-middle-dot rule: meta as separate chips (size, rules, moves, duration, date), not `17×17 | Wall + Portal | …`.
- `a11y-aria-keyboard-focus`: native `<input type=range>` with `aria-valuetext`, the speed control as a `pseg` of `aria-pressed` buttons, `aria-current="step"` on the current move. **DOM order must match the visual order**. The mockups reorder with CSS `order` on the phone, and the implementation must not: the DOM order is players → board → controls → list, and the desktop places them with grid areas.
- `a11y-wcag-essentials`: every control keeps a visible focus outline.

## 2. Behaviour decisions (implementation)
- **Winning line: not highlighted.** User decision 2026-11-27: the server does not store the winning rule, so no client-side highlight (`winLine: null`). Revisit with #501.
- **Times**: both `moveHistory.push` sites write `timestamp: Date.now()`. On the local (stale) DB, all 949 casual games with moves have a timestamp on every move. The 2 of 19 tournament games without one have 0 moves (a resign or timeout before move 1). Production was not queried. Think time of move *i* = ts[i] − ts[i−1]. Move 1 shows "—" (started_at ≈ ts[0]). Duration = `ended_at − started_at`. If any move lacks a numeric timestamp, the time column and the duration chip are hidden.
- **Deep link**: `?move=N` (main-line ply, 0 = empty board) is read on load and clamped. Share copies `location.origin + /replay/<id>?[source=tournament&]move=N`, and a toggle chooses this move or the game start. The URL stays in sync through `history.replaceState`, with no history spam.
- **Speed**: `pseg` 0.5× / 1× / 2× = 1200 / 600 / 300 ms, remembered in localStorage (`gvn_replay_speed`).
- **Coordinates**: the move list must use the board's column letters. The current MoveTree skips "I", so the board shows O9 while the list says P9 (#499, a separate fix).
- The `alert()` on a load error becomes an inline `pnote` (no browser dialogs).

## 5. Decision 2026-11-27: variant A, with modernised widgets first
The style is flat 2.0, following `vpick-trends-longevity` (flat 2.0 as a durable base) and `vbase-depth-motion` (strong signifiers, controls with a 3:1 boundary, transform/opacity motion of 120–180 ms, honouring reduced motion).
- Timeline: a 6 px rounded track filled in brand up to the cursor, an elevated knob with a focus ring, accent dots at variation branch points, and the counter in a pill.
- Transport: one dock surface. Four icon buttons are transparent with a tinted hover. Play is a raised, round 56 px brand button.
- Speed: a pill-shaped segmented control whose elevated indicator slides between options.
- Secondary actions: tonal pill buttons (Share in brand tint, Delete branch in danger tint). Analysis is a `role=switch` toggle beside the list title.
- Player card on a `surface-2` block, with a tonal "Thắng" pill and a trophy icon. Meta chips are outlined pills.
- Move list: soft rows. The current move gets a brand tint and a 3 px brand bar. Think times sit in small pills. Variation rows get an accent tint and an accent bar.
- Page-local tokens in `replay.css` (`--rp-r`, `--rp-r-lg`, `--rp-elev`, `--rp-ring`) built on tokens.css. Moving them into platform.css is a later, separate decision.
