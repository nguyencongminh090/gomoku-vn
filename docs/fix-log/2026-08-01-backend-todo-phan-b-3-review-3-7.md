# Fix log entry — 2026-08-01 23:04

## Prompt

Backend TODO Phần B #3 (review 3.7): `escapeAttr` in [client/js/lobby.js:474](client/js/lobby.js#L474) and [client/js/room-ui.js:62](client/js/room-ui.js#L62) backslash-escaped quotes (`str.replace(/'/g, "\\'").replace(/"/g, '\\"')`). Backslashes are meaningless to an HTML parser, so `\"` inside a double-quoted attribute still closes that attribute and the remainder is read as further attributes (e.g. `onerror=`). `instruction.md` §B3 confirms nothing is exploitable today — the only values passed are server-generated `roomId`/`userId` — and scopes the fix as preventive, for whenever someone reuses the helper for `roomName`/`displayName`.

## Action

Extracted escaping into a new pure UMD module [client/js/escape-utils.js](client/js/escape-utils.js) (same dual CommonJS/browser-global pattern as `profanity-filter.js`), exporting `escapeAttr` (now `&amp;`/`&quot;`/`&#39;`/`&lt;`/`&gt;`) and `escapeJsString` (backslash escaping plus `\n`/`\r`/`\u2028`/`\u2029`). `lobby.js` and `room-ui.js` now alias into it instead of each defining their own copy; the four call sites keep the same shape. Added `import './escape-utils.js'` to [index-entry.js](client/js/index-entry.js) and [room-entry.js](client/js/room-entry.js) ahead of their consumers, and bumped the shared cache-bust `?v=26` → `?v=27` across all 45 occurrences (4 HTML files + 3 entry files) per the CLAUDE.md rule.

## Decision

**Deviation from `instruction.md` §B3, deliberate and noted per the CLAUDE.md deviation rule:** applying the prescribed `&quot;`/`&#39;` swap *alone* would have introduced a new hole at two of the four call sites. `lobby.js:208` and `room-ui.js:461` interpolate into `onclick="joinRoom('…')"` — a JS string literal nested inside an HTML attribute. An HTML parser decodes entities in the attribute value *before* the JavaScript is parsed, so `&#39;` becomes a real `'` in the JS source and closes the literal early; entity escaping is correct for the attribute context and actively wrong for this nested one. Hence two functions rather than one, with the nested sites composing them as `escapeAttr(escapeJsString(x))` — entity-safe for the attribute, backslash-safe for the literal. The two plain-attribute sites (`data-room-id`, `class`) use `escapeAttr` alone, exactly as the review asked. Extraction into a shared module (rather than editing both copies in place) follows the option TODO Phần B #3 itself suggested, and is what makes the helper testable from Node without standing up jsdom. Left `escapeHtml` untouched in both files — it is DOM-based, correct, and outside this item. Also corrected a stale claim in `TODO.md`: Jest's `testMatch` is `**/tests/**/*.test.js`, not `server/tests/**` only.
