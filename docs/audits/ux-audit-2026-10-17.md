## Findings
**H1 — `<a class="pbtn pbtn--primary">` loses its text colour inside `.pl`** · Layer Visual · High
Surface: `/puzzles.html`, light skin, all viewports ("Đăng puzzle mới").
Reproduce: open /puzzles.html as member → axe color-contrast.
Observed: text #2b2926 on #4d7c1f = 2.91:1. Expected ≥ 4.5 (#fff on #4d7c1f = 4.98).
Evidence: `docs/audits/2026-10-17/puzzles-1280-before.png`. Cause: `.pl a { color: inherit }` (0,1,1) beats `.pbtn--primary { color: var(--c-on-brand) }` (0,1,0).
Location: `client/css/platform.css:12` vs `:70`. Patch: add `.pl a.pbtn--primary { color: var(--c-on-brand); }` after line 70. Check other `<a class="pbtn--primary">` (puzzles-mine, clubs) after.

**H2 — forum "posting too fast" error text fails contrast in the dark skin** · Visual · High
Surface: `/forum.html`, dark skin, post two threads within the cooldown.
Observed: `#fm-new-result` #ef6a6a on #33312e = 4.28:1 (needs 4.5). Same token also on `--c-fill` panels elsewhere.
Evidence: `docs/audits/2026-10-17/forum-error-dark.png`.
Location: `client/css/tokens.css:39` (`--c-error`, dark). Patch: `--c-error: #f77f7f` (5.12 on #33312e, 5.43 on #2f2d29); re-run axe on forum/puzzles/clubs in dark.

**M1 — lobby at 375 px shifts layout during load (CLS 0.135)** · Visual · Medium
Under the 0.25 gate but 13× the other pages. Reproduce: load `/` at 375×812, watch CLS. Location: lobby home blocks that render after `/api/home` (see `lobby-cls-reserve.test.js`). Patch: reserve the min-height of the block that grows; re-measure.

**M2 — `/profile.html` without a username 404s** · Interaction · Medium
`/profile.html` calls `/api/profile/%2Fprofile.html` → 404 + console error (reached only by typing the file URL; `/u/<name>` is clean, axe 0). Patch: in `client/js/profile.js:283` redirect to `/` when the path has no `/u/` segment.
