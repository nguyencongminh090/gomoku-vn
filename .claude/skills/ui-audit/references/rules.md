# ui-audit rules table

Each row: `| id | severity | check | detect | note#section |`. The last column names a note in
`knowledge/visual-design/items/` or `knowledge/web-development/items/` (without `.md`) and a `##` heading in it; read that section for the
reasoning. Severity: block (unusable or inaccessible), major (clearly hurts users), minor (polish).
`detect` is a grep hint or what to inspect; "visual" means only a screenshot shows it.
Validate with `skills/frontend-ui-design/kit/web-visual/tests/check_rules.sh`.
